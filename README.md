# ⚖️ Legal Saarthi

An AI-powered legal assistance platform that helps users understand basic legal concepts, access legal document templates, and get instant legal guidance using Google's Gemini AI.

---

## 🚀 Features

- 🤖 AI Legal Assistant (Gemini API)
- 📄 Legal Document Templates
- ⚖️ Know Your Rights Section
- ❓ Frequently Asked Questions
- 📞 Contact Form
- 🌙 Dark Mode UI
- 📱 Responsive Design

---

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/satvikawasthi80-byte/Legal-Saarthi.git
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Create Environment File

Create a `.env` file inside the **backend** folder.

```env
GEMINI_API_KEY=YOUR_API_KEY
PORT=5000
```

### Start Backend

```bash
npm start
```

Open `frontend/index.html` in your browser.
